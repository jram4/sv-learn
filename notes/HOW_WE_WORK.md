# How we work (foundation)

1. Write the question yourself.
2. Search / read docs (Level 0).
3. Reconstruct on paper in `notes/`.
4. Implement from a blank file in `rtl/`.
5. Simulate; form a hypothesis before asking AI.
6. Live tutoring: ChatGPT under SYSTEMS meta prompt.
7. Say `end session` → paste handoff to SYSTEMS.

Max ladder: L0 → L1 → L2 → L3 → L4 → L5 → L6 (last resort + rebuild).
