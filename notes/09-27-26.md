	output logic y,

endmodule

- module (name) starts definition
- input logic a logic b are bit inputs
- logic y is bit output.
- assign y = a & b is continous
- endmodule closes the module

To write a test bench

module (tb name); 
	//instantiate inputs and outputs
	logic a, b;
	logic y;

	//write component DUT design under test,

	and_gate dut (
		.a(a),
		.b(b),
		.y(y)
	);

	//observe outputs, given its a continuous component
	initial begin
		//set inputs
		a = 0; b = 0; #1;
		//verify observation
		assert (y === 0);

		a = 0; b = 1; #1;
		assert (y === 0);
		
		a = 1; b = 0; #1;
		assert (y === 0);
		
		a = 1; b = 1; #1;
		assert (y === 1);

		//display finish
		$display("PASS");
		$finish;
	//end observation
	end
endmodule

Timescale

- 1ps = simulation precision
